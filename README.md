# Gin

Example [Gin](https://gin-gonic.com/) app. Gin is a fast and popular HTTP web framework for Go.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `8080` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# start the app
go run main.go
```
