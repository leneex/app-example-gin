# Gin

Пример приложения [Gin](https://gin-gonic.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8080` |
| Путь проверки состояния | `/` |

Приложение слушает порт из переменной окружения `PORT` — её передаёт платформа, — а без неё `8080`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск приложения
go run main.go
```
